# A 股每日简报

description: 面向 A 股盘前和盘后场景的短线市场简报。汇总指数表现、市场
成交额、涨跌家数、涨停跌停、连板梯队、热门行业和概念变化、重要政策、
公告、新闻、外围市场影响，并给出当日重点观察方向。适用于“生成明天 A 股
盘前简报”、“今天盘后复盘”、“A 股早会材料”等请求。

## Workflow

### Step 1: Define Brief Type

先确认简报类型和覆盖范围：

- **盘前简报**：关注隔夜信息、今日事件、外围市场、政策新闻和开盘观察方向。
- **盘后简报**：关注当日市场结构、题材轮动、涨跌停、连板梯队和次日观察点。
- **覆盖范围**：全市场、指定指数、指定行业、指定题材或用户给定股票池。
- **时间戳**：写明简报生成时间，避免把盘中变化当成最终结论。
- **数据来源**：用户提供、交易所、公司公告、公开行情、新闻或第三方数据。

### Step 2: Market Context

汇总市场状态，无法验证的数据必须标记：

**指数与成交**
- 上证指数、深证成指、创业板指、科创 50、北证 50 等主要指数表现。
- 沪深北成交额、较前一交易日变化、放量或缩量情况。
- 北向资金、融资融券或 ETF 流向，如果数据可得。

**市场宽度**
- 上涨家数、下跌家数、涨停家数、跌停家数。
- 连板高度、晋级率、炸板率和高标反馈，如果数据可得。
- 大盘股、中小盘、微盘股的风格差异。

**行业与题材**
- 涨幅居前和跌幅居前的行业。
- 热门概念、题材主线和扩散方向。
- 题材强度变化：新发酵、延续、分歧、退潮或修复。

**事件与外围**
- 重要政策、监管动态、产业新闻和宏观数据。
- 公司公告、业绩预告、业绩快报、解禁、减持和停复牌。
- 美股、港股、人民币汇率、商品、利率和海外政策事件的影响。

### Step 3: Brief Format

简报要短，优先让交易员和研究员在 2 分钟内读完：

---

**[日期] A 股[盘前/盘后]简报**

**Top Call: [一句话主线]**
- 2 到 3 句话说明最重要变化、影响方向和需要观察的验证点。
- 写清事实、推断和不确定性。

**市场概览**
- 指数与成交：[数据或来源缺失说明]
- 市场宽度：[涨跌家数、涨停跌停、连板高度]
- 风格表现：[大盘/中小盘/微盘、成长/价值等]

**题材与行业**
- [题材 A]：[变化 + 代表股票或环节 + 风险]
- [题材 B]：[变化 + 代表股票或环节 + 风险]
- [行业/概念]：[变化 + 观察点]

**重要事件**
- [政策/公告/新闻]：[事实 + 影响范围 + 待验证点]
- [公司事件]：[代码/简称 + 事件 + 风险]

**今日/次日观察**
- [方向 1]：[触发条件 + 失效条件]
- [方向 2]：[触发条件 + 失效条件]

---

### Step 4: Quick Takes On Events

如果出现重要公告、财报或突发事件，补充快速点评：

| 事件 | 相关股票 | 事实 | 可能影响 | 待验证点 | 风险 |
|------|----------|------|----------|----------|------|
| | | | | | |

**Our Take**：用 2 到 3 句话说明这件事为什么重要、影响哪个题材或行业、
以及需要观察什么后续信号。

### Step 5: Output

- 默认输出 Markdown，控制在 1 页以内。
- 必须区分已验证数据、用户提供数据和来源缺失信息。
- 必须包含风险提示和失效条件。
- 不直接给出买入、卖出、加仓或减仓指令。
- 如果没有重大信息，明确写“暂无可验证的重大新增信息”，不要硬凑观点。

## Important Notes

- 盘前简报重在“今天看什么”，盘后简报重在“今天发生了什么和明天验证什么”。
- A 股短线简报不能只总结新闻，必须指出主线、分歧、风险和待验证条件。
- 如果没有实时行情权限，不要编造指数涨跌、成交额、涨停家数或连板梯队。
- 对政策、公告和新闻要写明来源和时间；无法确认时必须显式标记。
- 输出是研究辅助，不构成投资建议或交易指令。
