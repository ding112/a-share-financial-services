# A 股题材筛选

## Workflow

### Step 1: Define Search Criteria

先确认筛选边界，避免把泛概念当成可交易题材：

- **题材或事件**：政策、新闻、产业趋势、公告、业绩变化或市场主线。
- **市场范围**：沪市、深市、北交所、科创板、创业板或全 A。
- **时间窗口**：当日、近一周、近一月或特定事件前后。
- **相关性口径**：主营业务、收入占比、公告披露、客户供应链或市场标签。
- **剔除条件**：ST、停牌、流动性不足、重大监管风险或信息不可验证。
- **数据来源**：用户提供、公开资料、交易所公告、公司公告或第三方数据。

### Step 2: Topic And Value Chain Mapping

对题材做拆解，先判断主线是否足够具体：

1. 定义题材逻辑，例如“机器人产业政策加速，核心零部件和本体厂商受益”。
2. 拆分产业链位置：上游材料、核心零部件、设备、本体、系统集成、应用场景。
3. 标记直接受益与间接受益，避免只因概念标签就纳入核心池。
4. 对照公告、财报、互动平台、交易所问询和新闻来源验证相关性。
5. 记录无法验证的信息，并在输出中显式标记。

### Step 3: Stock Pool Classification

按相关性和短线位置给股票池分层：

**核心标的**
- 主营业务或收入结构与题材直接相关。
- 有公告、财报、订单、客户或产能信息支撑。
- 在题材中承担关键环节，市场识别度较高。

**跟涨标的**
- 业务相关但弹性或纯度低于核心标的。
- 可能受板块情绪、同产业链映射或资金扩散影响。
- 需要说明跟涨逻辑和与核心标的的差异。

**补涨候选**
- 相关性存在但尚未充分反映在市场表现中。
- 需要额外验证成交额、换手、公告催化和板块扩散强度。
- 不把“涨得少”单独作为补涨理由。

**低相关或弱相关标的**
- 只有概念标签、互动平台表述或远期规划，缺少收入和业务验证。
- 业务占比低、题材贡献不清晰，或逻辑链条过长。

**需要剔除的风险标的**
- ST、退市风险、停牌、重大监管处罚、财务异常或流动性不足。
- 大额解禁、减持、业绩大幅下滑、重大诉讼或问询函未解决。

每个候选理由保持 1 到 3 句话，必须回答：

- 为什么它和题材相关。
- 相关性来自哪个环节或证据。
- 还需要验证什么。
- 什么情况会让这条题材逻辑失效。

### Step 5: Output

- 输出 5 到 20 只候选股票，除非用户明确要求更大股票池。
- 先给结论分层，再给验证来源和风险提示。
- 明确说明数据来源；如果没有实时数据，写明“数据来源缺失或未验证”。
- 不直接给出买入、卖出、加仓或减仓指令。
- 对高不确定性信息使用“待验证”、“无法验证”或“仅作线索”标记。

## Important Notes

- 题材筛选只生成研究线索，不构成投资建议。
- A 股短线题材变化快，必须区分事实、市场解读和交易情绪。
- 不要把概念标签等同于业务实质；优先使用公告、财报和交易所文件。
- 核心标的不一定是最好的短线候选，输出必须同时列出风险和失效条件。
- 如果无法访问实时行情或数据库，不要编造涨跌幅、成交额、连板数或排名。
- 对政策和新闻要写清发布时间、来源和适用范围。
