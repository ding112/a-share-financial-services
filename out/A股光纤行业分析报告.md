# A股光纤行业分析报告

**日期**: 2026年5月16日
**分析师**: Claude Code

---

## 一、行业/主题定义

光纤（Optical Fiber）是以玻璃或塑料制成的纤维，利用全反射原理进行光传导的通信介质。光纤行业涵盖从光纤预制棒、光纤拉丝、光缆制造到光器件、光模块的完整产业链，是现代通信网络的基础设施。

---

## 二、产业链结构

### 上游（原材料）
| 环节 | 产品 | 代表企业 |
|------|------|----------|
| 光纤预制棒 | 核心原材料，占光纤成本约70% | 长飞光纤、中天科技、亨通光电 |
| 高纯石英材料 | 预制棒原料 | 菲利华、石英股份 |
| 特种气体/化学材料 | 辅助材料 | 飞凯材料（紫外固化涂覆材料） |
| 芳纶 | 光缆加强件 | 泰和新材 |

### 中游（光纤光缆制造）
| 环节 | 产品 | 代表企业 |
|------|------|----------|
| 光纤拉丝 | 将预制棒拉制成光纤 | 长飞光纤、烽火通信、亨通光电 |
| 光缆制造 | 光纤成缆 | 中天科技、通鼎互联、金信诺 |
| 光器件/光模块 | 光电转换器件 | 中际旭创、新易盛、光迅科技 |

### 下游（应用领域）
| 领域 | 需求方 |
|------|--------|
| 电信运营商 | 中国移动、中国电信、中国联通 |
| 数据中心/云计算 | 互联网巨头、IDC运营商 |
| FTTH（光纤到户） | 家庭用户 |
| 5G网络建设 | 电信运营商 |
| 海缆/海底光缆 | 跨洋通信、海上风电 |

## 三、市场规模与增长

### 市场规模
- **全球市场规模**: 预计2025-2026年达到约200-250亿美元（来源缺失）
- **中国市场规模**: 预计2025年约800-1000亿元人民币（来源缺失）
- **全球份额**: 中国占全球光纤光缆市场约50%以上（来源缺失）

### 增长预测
- **2024-2026年CAGR**: 预计约5-8%（来源缺失）
- **海缆/海底光缆**: 增长更快（来源缺失）

> ⚠️ **注意**: 以上市场规模和增长数据为行业估算值，具体数字请以中国信通院、CRU Group、LightCounting等权威机构最新报告为准。

## 四、关键驱动与为什么是现在

### 核心驱动因素

1. **AI算力需求爆发**
   - AI大模型训练/推理对数据中心互联（DCI）需求激增
   - 800G/1.6T高速光模块需求旺盛
   - 供需错配下光芯片与光纤光缆环节涨价逻辑确认（来源：国泰海通证券，2026-05-12）

2. **物料紧缺**
   - 物料紧缺已成为核心预期锚（来源：东方财富网，2026-05-12）
   - 中国光纤光缆企业爆单，疯狂连夜加速生产（来源：每经AI快讯，2026-05-15）

3. **政策支持**
   - "十四五"新型基础设施建设规划
   - 东数西算工程
   - 千兆光网覆盖政策
   - 算力基础设施高质量发展政策

4. **海外需求恢复**
   - 全球光纤光缆运输到世界各地
   - 港股光通信股延续涨势，长飞光纤涨超8%（来源：东方财富网，2026-05-11）

5. **技术升级**
   - 空芯光纤、多芯光纤等新技术方向
   - 骨干网400G/800G光传输升级

## 七、投资要点总结

1. **供需错配是当前核心逻辑**: AI算力需求爆发导致光纤光缆物料紧缺，涨价预期明确
2. **产业链龙头受益**: 长飞光纤（预制棒+光纤）、亨通光电（海缆）、中天科技（光缆+海缆）为核心标的
3. **光模块是高弹性方向**: 中际旭创、新易盛受益于800G/1.6T光模块需求
4. **关注政策催化**: 东数西算、千兆光网等政策持续推进
