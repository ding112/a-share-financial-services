# A 股短线事件、题材与量化筛选助手路线图

本文记录将现有金融服务插件仓库扩展到 A 股短线研究场景的路线图。
目标是先做一个轻量、可验证的垂直插件，再逐步扩展到 named agent。

## 定位

`china-equity-trading` 面向 A 股短线研究、题材跟踪、事件筛选和股票池
辅助分析。它不做自动下单，不承诺收益，也不替代投资决策。

核心输出包括：

- 题材和概念主线梳理。
- 短线事件、公告、财报、解禁、减持等催化剂跟踪。
- 盘前和盘后市场简报。
- 候选股票池筛选、风险提示和失效条件。

## 第一阶段：新增垂直插件

先新增 `plugins/vertical-plugins/china-equity-trading`。

这一阶段只建立插件骨架和基础说明，遵循现有 `vertical-plugins` 的组织方式：

- `.claude-plugin/plugin.json` 定义插件名称、版本和描述。
- `skills/` 存放 A 股短线研究技能。
- `commands/` 后续按需要提供显式命令入口。

第一阶段不改动现有 `equity-research`、`financial-analysis` 或 agent 插件。

## 第二阶段：第一版核心技能

第一版只迁移和改造 3 个技能，保证范围小、可测试、可迭代。

### `a-share-topic-screen`

从 `idea-generation` 改造，面向 A 股题材和概念筛选。

它负责根据题材、行业、政策、新闻或市场主线，输出相关股票池，并区分：

- 核心标的。
- 跟涨标的。
- 补涨候选。
- 低相关或弱相关标的。
- 需要剔除的风险标的。

### `a-share-daily-brief`

从 `morning-note` 改造，面向 A 股盘前和盘后简报。

它负责汇总：

- 指数表现和市场成交额。
- 涨跌家数、涨停跌停、连板梯队。
- 热门行业、概念和题材变化。
- 重要政策、公告、新闻和外围市场影响。
- 当日需要重点观察的方向。

### `a-share-event-calendar`

从 `catalyst-calendar` 改造，面向 A 股事件日历。

它负责跟踪：

- 财报披露。
- 业绩预告和业绩快报。
- 限售解禁。
- 股东减持。
- 停复牌。
- 股东大会。
- 监管函和问询函。
- 政策会议、产业大会和行业事件。

## 第三阶段：第二版筛选与风控

第二版再新增 2 个技能，补齐短线筛选和风险过滤。

### `a-share-quant-screen`

用于量化初筛候选股票池。第一版指标保持简单，避免过度设计。

可覆盖的筛选维度包括：

- 涨跌幅。
- 成交额。
- 换手率。
- 量比。
- 均线位置。
- 相对强弱。
- 板块强度。
- 估值分位。
- 基础财务质量。

### `a-share-risk-check`

用于剔除或标记短线风险。

可覆盖的风险维度包括：

- ST 或退市风险。
- 停牌和复牌。
- 大额解禁。
- 股东减持。
- 监管函、问询函和处罚。
- 业绩大幅下滑或亏损。
- 高商誉。
- 高质押比例。
- 流动性不足。

## 第四阶段：封装 named agent

最后新增 `plugins/agent-plugins/a-share-screener`。

该 agent 聚合前面的技能，形成完整工作流：

1. 读取市场上下文。
2. 识别题材主线。
3. 生成候选股票池。
4. 执行量化初筛。
5. 执行风险检查。
6. 输出短线研究清单。

默认输出不超过 10 到 20 只候选股票。每只股票都需要包含：

- 股票代码和简称。
- 所属行业和概念。
- 触发事件或题材逻辑。
- 量化特征。
- 风险点。
- 观察条件。
- 失效条件。

## 数据源方向

数据源先做抽象描述，后续再决定具体接入方式。

候选数据源包括：

- Wind。
- Choice。
- 同花顺 iFinD。
- Tushare。
- AkShare。
- 巨潮资讯。
- 上交所、深交所和北交所公告。
- 东方财富、同花顺等公开行情和概念数据。

第一版不强行绑定某个供应商，避免在插件结构还没稳定时引入过多耦合。

## 验收标准

第一版完成后，用以下样例请求验收：

- “筛选今天机器人题材相关 A 股。”
- “生成明天 A 股盘前简报。”
- “列出下周有业绩预告、解禁或减持风险的股票。”

合格输出必须包含：

- 中文输出。
- 数据来源或来源缺失说明。
- 候选理由。
- 风险提示。
- 不可验证信息标记。
- 不直接给出买入或卖出指令。

## 推荐实施顺序

推荐按以下顺序推进：

1. 创建 `china-equity-trading` 垂直插件骨架。
2. 实现 `a-share-topic-screen`。
3. 实现 `a-share-daily-brief`。
4. 实现 `a-share-event-calendar`。
5. 运行 `python3 scripts/check.py`。
6. 根据样例请求调整技能描述和工作流。
7. 增加 `a-share-quant-screen`。
8. 增加 `a-share-risk-check`。
9. 封装 `a-share-screener` named agent。
