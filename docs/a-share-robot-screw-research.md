# A股机器人产业链研报：丝杠（螺杆）方向

## 行业/主题定义

**丝杠**（Ball Screw / Planetary Roller Screw）是将旋转运动转化为直线运动的精密传动部件，是机器人关节执行器的核心零部件之一。在人形机器人中，行星滚柱丝杠（PRS）因其承载能力强、精度高、寿命长、体积紧凑的特点，被广泛用于线性关节（如膝关节、肘关节的线性驱动），是当前A股市场机器人产业链中"国产替代弹性最大"的细分赛道之一。

```

      热处理设备                                      航空航天
      在线检测仪器                                    新能源汽车（线控底盘）
                                                      半导体设备
```

**上游关键瓶颈：** 高精度螺纹磨床依赖进口（日本Saoki、瑞士Studer等），材料纯净度和热处理变形控制是核心难点。

**中游技术壁垒：** 精度等级需达C3-C5级（微米级定位精度），螺纹滚道精密磨削工艺需长期积累，批量化生产的一致性和可靠性控制是最大挑战。

## 关键驱动与为什么是现在

### 1. 需求端催化

- **Tesla Optimus Gen 2持续迭代**：明确使用行星滚柱丝杠作为线性关节方案，市场对丝杠需求预期大幅提升
- **中国人形机器人企业加速**：优必选（Walker S）、宇树科技（G1/H1）、小鹏（PX5 Iron）、傅利叶智能（GR-2）等持续推进，华为提供底层AI赋能
- **2025年被视为人形机器人量产元年**：多家企业宣布小批量量产目标

### 2. 政策加码

- 工信部《人形机器人创新发展指导意见》（2023.11）：要求突破丝杠等关键核心零部件
- 大规模设备更新政策（2024年）：推动数控机床换代，间接拉动丝杠需求
- 北京、上海、深圳、重庆等地密集出台配套政策

### 3. 国产替代提速

- 国产丝杠精度已接近C5-C7级，部分企业进入特斯拉供应链体系
- 但精度保持性、批量一致性、使用寿命方面与国际一流仍有差距

## 核心风险提示

1. **人形机器人量产节奏不及预期**——丝杠需求高度依赖下游量产进度
2. **技术路线变化风险**——执行器方案调整可能影响丝杠需求
3. **国产替代进度不及预期**——高端丝杠技术壁垒极高，突破周期长
4. **前期炒作后估值回调**——2024年A股丝杠板块已有较大涨幅
5. **价格竞争加剧**——国产厂商间价格竞争可能压缩利润空间
