# 03 — 贯通现金流量表与统一报告期窗口

**What to build:** 完成第三张报表的端到端路径，并把资产负债表、利润表和现金流量表统一到公司级“财务报表报告期窗口”。研究人员可以获得默认最近 12 个可见报告期的完整三表长表，缺期被显式记录而不会由更早期间补位。

**Blocked by:** 02 — 贯通利润表明细

**Status:** completed

- [x] 在线路径通过现有 AkShare 单公司现金流量表接口获取数据，fixture 使用真实宽表形状；不增加直接东方财富适配器或其他来源。
- [x] 现金流量表记录进入同一个长表，使用 `statement_type=cash_flow_statement` 和 `value_semantics=year_to_date`。
- [x] 完整实现父规格中 7 个现金流量表核心科目的英文 snake_case 映射和固定顺序，包括经营、投资、筹资现金流、长期资产购置、现金净增加、期末现金及折旧摊销。
- [x] 保留所有已知、非空、独立披露的现金流量表金额或数量行；排除元数据、同比、来源计算比例和空的非核心字段。
- [x] 现金流量表核心映射、冲突处理、单位、占位行、验证状态、稳定身份和来源追溯遵循前两张表已建立的统一契约。
- [x] 在三张表完成基本结构和有效日期筛选后，以公司层面不同报告期的并集选择最近 `period-limit` 个期间；默认值为 12，且必须为正整数。
- [x] 三张表共享同一个期间集合，不各自独立补足数量；报告期数量限制不截断选定期间内的行项目。
- [x] 某张表完全没有记录时只写该证券/报表的 `*_no_data`，不制造核心占位行；仅缺窗口内某期时记录具体缺期，不用窗口外更早期间补位。
- [x] 报告期晚于研究截止日的记录不进入窗口；一季报、中报、三季报和年报均可进入，业绩预告和业绩快报不进入。
- [x] 最终排序固定为证券代码升序、报告期降序、资产负债表/利润表/现金流量表顺序、核心契约顺序和其他来源字段升序。
- [x] 来源清单更新为完整三表口径，说明资产负债表时点值、利润表与现金流量表年初至今累计值、共享期间窗口和不补位规则。
- [x] 黑盒 fixture 提供超过 12 个期间以及三表缺期，验证默认窗口、可配置窗口、缺期通知、不补位和稳定排序。
- [x] 成功场景验证所有三张表同时出现在固定长表中，且相同 fixture 重跑得到字节稳定的 CSV、来源条目和本阶段错误记录。
