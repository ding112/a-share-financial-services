# 02 — 贯通利润表明细

**What to build:** 在既有财务报表明细长表和公开入口中贯通利润表，使沪深证券的利润表原始披露项目、规范核心科目、每股收益和审计元数据与资产负债表共同输出，并沿用同一来源、身份、排序和黑盒验收契约。

**Blocked by:** 01 — 贯通资产负债表明细

**Status:** completed

- [x] 在线路径通过现有 AkShare 单公司利润表接口获取数据，fixture 模拟真实宽表字段和元数据；不增加平行来源或隐式回退。
- [x] 利润表记录进入同一个 `financial_statements.csv`，使用 `statement_type=income_statement` 和 `value_semantics=year_to_date`，不另建宽表或单表文件。
- [x] 保留所有已知、非空、独立披露的利润表金额和每股项目；元数据、同比字段、来源计算比例和空的非核心字段不生成行。
- [x] 完整实现父规格中 14 个利润表核心科目的英文 snake_case 映射和固定顺序，包括收入、成本、主要费用、利润层级、所得税、归母/少数股东利润及基本/稀释 EPS。
- [x] 基本和稀释 EPS 单位为 `CNY/share`，其他已知利润表金额单位为 `CNY`；不得把同比或来源计算比例当成金额行项目。
- [x] 利润表同义来源字段使用显式优先级；冲突候选仍保留原始行，只有一个候选获得规范名称，不执行求和、最大值或隐式派生。
- [x] 已有利润表记录缺少核心项目时生成父规格定义的核心占位行；整张利润表或某期利润表不存在时不批量生成占位行。
- [x] 国内和海外审计意见进入固定元数据列；非年报或来源未提供时写 `来源缺失`，不得推断为标准无保留意见。
- [x] 组织类型按来源保留，但不表示报表范围；`statement_scope` 继续保持 `来源缺失`。
- [x] 资产负债表既有行、来源条目和错误记录在加入利润表后保持完整，不因第二张表覆盖或重复。
- [x] 两类报表按资产负债表在前、利润表在后的固定顺序输出；每类报表内部继续遵循核心顺序和来源字段稳定排序。
- [x] 黑盒成功 fixture 同时验证沪深资产负债表和利润表、EPS 单位、审计意见、映射冲突、核心占位、来源清单及重复运行稳定性。
- [x] 自动化检查只调用公开命令并观察最终产物，不断言 AkShare 调用次数、内部映射 helper 或实现结构。
