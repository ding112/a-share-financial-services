# 05 — 接入一键准备与本地研究包

**What to build:** 把已可靠降级的财务报表明细作为默认执行、可显式跳过的补充阶段接入一键研究包，并让本地准备入口精确接纳标准长表。阶段失败只警告、不阻断核心研究包；强制跳过会清理陈旧财务报表产物。

**Blocked by:** 04 — 补齐可见版本和可信降级语义

**Status:** completed

- [x] 一键准备新增财务报表来源、报告期数量、fixture 场景和整体跳过参数，并把实际解析结果记录到自动准备清单。
- [x] 普通股票池默认解析为 AkShare，fixture 股票池默认解析为 fixture，显式来源参数优先；报告期数量默认为 12 且必须为正整数。
- [x] 未跳过时默认运行独立财务报表明细入口，并把 `financial_statements.csv` 纳入受管输出，不改变现有 `financial_summary.csv`。
- [x] 财务报表明细返回非零时，一键准备向标准错误输出包含阶段入口和退出码的警告，但核心研究包继续生成并保持成功退出语义。
- [x] 可选阶段失败后仍保留财务报表入口已经写出的固定表头 CSV、来源条目和错误记录，不能把失败伪装成未运行。
- [x] 显式跳过时不运行财务报表阶段，自动准备清单明确记录跳过状态。
- [x] 使用强制重跑并跳过时，删除陈旧 `financial_statements.csv`、对应来源条目和所有本阶段错误，同时保留其他阶段文件、来源条目和错误。
- [x] 一键准备重复运行不会产生重复来源条目或累积旧阶段错误，实际来源、期间数量和 fixture 场景可以复现。
- [x] 本地研究包准备入口精确识别并复制标准 `financial_statements.csv`，保持固定列顺序和内容，不做隐式转换。
- [x] 本地准备不支持旧别名、宽表猜测或自动转成长表；错误表头由研究包数据契约检查明确拒绝。
- [x] 一键准备成功、可选失败、显式跳过、强制跳过清理和本地复制场景都通过同一个公开 CLI 黑盒检查器验收。
- [x] 一键准备现有受管输出、核心完成条件和其他可选阶段行为保持不变。
- [x] 所有自动化集成场景使用 fixture，不访问真实 AkShare 或东方财富网络。

## Comments

- 2026-08-17 验收：一键准备默认不抓取投资者互动数据，`--include-investor-interactions` 显式启用时可正常运行；默认或强制重跑关闭后会清理陈旧 CSV、来源条目和阶段错误。财务报表阶段既有默认执行、失败警告和强制清理语义保持通过。
