# 04 — 补齐可见版本和可信降级语义

**What to build:** 让完整三表入口在历史研究、schema 漂移、北交所、无数据和来源故障下都可靠降级。任何无法证明可见性或含义的记录都不会被伪装成可用事实；局部问题保留其他结果，全部执行失败则在写完稳定产物后返回非零。

**Blocked by:** 03 — 贯通现金流量表与统一报告期窗口

**Status:** completed

- [x] 所有日期按 Asia/Shanghai 的研究截止日当日 23:59:59 判断；报告日晚于截止日的记录不进入候选。
- [x] 公告日晚于截止日的记录被视为当时尚不可见；若没有其他可见记录，写对应 `*_no_data`，不得纳入未来公告值。
- [x] 满足 `NOTICE_DATE <= as-of < UPDATE_DATE` 的当前记录被排除并写 `financial_statement_historical_version_unavailable`，不得把后来更新值回填历史研究包。
- [x] 公告日或更新日缺失、格式非法、更新时间早于公告日，或必要元数据无法解析时写 `financial_statement_schema` 并拒绝该报表记录，不能误报成真实无数据。
- [x] 同一证券、报表和期间存在多个可见候选时选择截止日前 `UPDATE_DATE` 最新者；完全重复候选确定性去重且不受返回顺序影响。
- [x] 非空的新来源字段即使不在显式目录中也保留原字段和值，规范名称和单位写 `来源缺失`、状态写 `待验证`，并留下 schema 漂移记录；不得猜测单位或静默丢弃。
- [x] 上交所和深交所为受支持范围；北交所不调用部分三表、不生成伪明细，写 `financial_statement_unsupported` 且不阻塞同批沪深结果。
- [x] 固定区分输入错误、三张表各自请求/解析失败、三张表各自真实无数据、北交所不支持、历史版本不可恢复和 schema 异常等父规格错误阶段。
- [x] 单张表失败只影响对应证券和报表，其他两张表、其他证券及既有研究包产物全部保留。
- [x] 至少一个受支持请求正常响应（包括正常空响应）时独立命令返回零；全部受支持证券的三类请求/解析都失败时，先写完稳定产物再返回非零。
- [x] 全部正常无数据、全部为北交所或只有历史版本不可恢复时返回零；这些数据缺口不能被当作执行崩溃。
- [x] 无论成功、无数据、部分失败、全失败或不支持，都生成完整表头 CSV、唯一来源清单条目和统一错误文件。
- [x] 重跑只替换财务报表明细 CSV、对应来源条目和 `financial_statement` 相关错误；其他阶段来源条目与错误保持不变，本阶段旧错误不累积。
- [x] 覆盖部分非法代码和全部非法代码：部分非法保留有效证券结果，致命输入情况留下稳定产物并返回非零。
- [x] 黑盒 fixture 覆盖沪深成功、北交所不支持、未来公告、截止日后更新、非法日期、重复候选、未知字段、真实无数据、一张表失败、全部失败和错误保留。
- [x] 相同 fixture 至少重复运行两次并验证 CSV、来源条目和本阶段错误记录字节稳定；自动化测试不访问网络。
