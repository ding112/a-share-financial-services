# A 股首次覆盖应用服务决策地图

Label: wayfinder:map

## Destination

形成一份可直接交给实施规划的应用服务决策规格：定义一个面向机构内部研究员、仅覆盖 A 股、按五阶段执行并由研究员逐阶段确认的首次覆盖 Web 应用，锁定其领域模型、数据与证据契约、产物契约、运行时、持久化、安全边界和 MVP 验收标准。

## Notes

- 本地图只解决实施前的决策，不编写或上线应用。
- 首版只有研究员账号；阶段门禁是研究员自确认，不是独立复核或正式发布审批。
- 五个阶段是公司研究、财务建模、估值分析、图表生成和最终报告组装；每次只执行一个阶段。
- 首版只支持 A 股上市公司，采用公开数据自动获取与研究员上传材料并存的混合输入。
- 缺少可靠来源的字段必须显式缺失，不得由模型补造。
- 模型可以生成估值草案；正式目标价和评级必须由研究员填写并确认。
- 用户交付物保持为研究 Markdown、财务模型 XLSX、估值 Markdown 与模型估值页、图表 ZIP、最终 DOCX。
- 已确认阶段产物不可原地覆盖；重跑产生新版本，确认绑定明确版本。
- 应用采用私有部署、单一机构边界；首版不做多租户 SaaS。
- 能力源与应用运行时使用两个仓库；本仓库继续保存 Skills、Prompt、领域契约与校验规则。
- 应用状态机由代码控制；OpenAI Agents SDK 负责阶段内 Agent 执行，DeepSeek V4 Pro 通过兼容接口作为默认模型，Provider 保持可替换。
- 东山精密（002384.SZ）是首版端到端基准案例，公开接口仍接受其他 A 股代码。
- 处理本地图时应使用 `wayfinder`、`grilling` 和 `domain-modeling`；涉及外部产品能力时使用 `research` 与 `openai-docs`；涉及 A 股来源时参考 `a-share-data-sources`。

## Not yet specified

- 首版应承载的并发项目数、单阶段最长运行时间和故障恢复目标；待运行时与产物规模明确后再判断是否需要独立决策。
- 模型评估失败时的降级、重试和人工接管粒度；待阶段质量门与 DeepSeek 能力原型明确后再细化。

## Out of scope

- 非 A 股市场、非上市公司和跨市场统一会计口径。
- `initiating-coverage` 以外的 Agent 或研究工作流。
- 首次覆盖完成后与季度业绩更新、thesis tracking 的衔接。
- 管理员、独立复核人、机构间协作和多租户 SaaS。
- 原生桌面端、移动端和面向普通投资者的公开产品。
- 无研究员确认的一键五阶段自动执行。
- 自动给出或发布买入、卖出、目标价、收益承诺或交易指令。
- 正式报告发布、分发、合规签署和交易执行。
