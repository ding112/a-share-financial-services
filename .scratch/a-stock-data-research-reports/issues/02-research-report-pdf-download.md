# 安全下载并复用限量研报 PDF

Status: completed

## What to build

在已贯通的个股研报索引路径上增加研报材料下载：从每个证券的稳定索引中选择最新报告，默认下载最多 3 份 PDF，并在一键准备流程中默认启用。使用者可以明确跳过 PDF 下载而保留索引。

下载必须是安全、可审计和可重复的。有效的既有 PDF 应被复用；非 PDF 响应、过小响应、危险文件名、越界路径和单份下载失败必须被拒绝并记录，但不能删除对应索引行或阻断核心数据包。真实第三方研报不得进入版本控制或测试 fixture。

## Acceptance criteria

- [x] 独立研报抓取入口和一键准备入口支持每个证券的 PDF 上限；默认从索引中选择最新 3 份。
- [x] 一键准备默认下载限量 PDF，并提供明确的跳过选项；跳过时索引仍正常生成，研报材料目录保持稳定形状。
- [x] PDF 选择顺序与索引的发布日期、稳定报告 ID 顺序一致，相同输入重复运行选择结果不漂移。
- [x] PDF 文件名包含稳定报告 ID 和经过清理、截断的可读元数据；索引只保存研究数据包内的相对路径，写入不能越出研报材料目录。
- [x] 下载响应必须通过成功状态、合理最小大小和 PDF 文件签名检查；HTML、错误页或其他非 PDF 内容不得作为有效文件保留。
- [x] 已存在且验证有效的 PDF 在普通重复运行时直接复用，不重复请求；强制刷新索引也不会无条件重复下载相同有效内容。
- [x] 单份 PDF 下载失败时保留对应索引行，将本地相对路径标记为 `来源缺失`，并写入 `research_report_pdf` 错误记录。
- [x] 部分或全部 PDF 失败不改变索引阶段的成功记录，不阻断独立索引结果，也不阻断一键准备的核心数据包。
- [x] 来源清单单独声明研报材料目录，包含 `third_party`、`待验证`、下载上限、跳过状态和缺失行为；下载成功不会升级证据等级。
- [x] 真实 PDF 只写入被版本控制忽略的运行输出；fixture 使用合成 PDF，不包含真实第三方研报内容。
- [x] 端到端 fixture 检查覆盖成功下载、跳过下载、部分失败、非 PDF 响应、安全文件名和重复运行复用，不断言私有下载函数。
- [x] 使用说明解释默认下载上限、跳过选项、第三方证据边界和错误排查入口。
- [x] 研报专项检查、现有 A 股数据契约检查、一键准备检查和仓库总检查全部通过，且未新增运行时依赖。
