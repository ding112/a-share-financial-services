# 贯通个股研报索引与一键数据准备

Status: completed

## What to build

为现有 A 股公开数据准备流程增加第一条可运行的研报索引路径：以股票池和 `as-of` 为输入，通过东方财富研报源检索个股研报，把稳定、限量、可审计的索引写入研究数据包，并让一键准备流程默认执行该可选阶段。

本切片只交付研报索引，不下载 PDF，但必须预留稳定的研报材料目录形状。研报索引属于补充数据源，统一标记为 `third_party`、`待验证`，不得改变现有行情、财务、年报、风险或下游 shortlist 行为。无数据、部分失败和全部失败必须具有不同的可观察结果；研报阶段完全失败不得阻断核心数据包。

实现应沿用现有脚本、来源清单、错误记录和 fixture 检查模式，不新增运行时依赖。外部 `a-stock-data` 仅作为端点与请求模式参考；若直接改编其代码，保留 Apache-2.0 所需归属。

## Acceptance criteria

- [x] 独立研报抓取入口接收股票池、`as-of`、回溯天数和每个证券的索引上限；默认回溯 730 天、每个证券最多 20 条。
- [x] 默认只检索股票池内的个股研报，不发起行业研报请求，也不推断行业代码。
- [x] 研报索引具有稳定列契约，至少包含报告 ID、范围类型、证券标识、标题、机构、发布日期、报告类型、评级、原始盈利预测字段、详情链接、PDF 链接、本地相对路径、来源类型、来源名称、验证状态和口径。
- [x] 结果按发布日期降序、稳定报告 ID 次序排序；重复记录按稳定身份去重，相同输入重复运行不产生顺序漂移。
- [x] 索引行统一标记为 `third_party`、`待验证`；评级、预测和观点不会写入现有财务摘要、业务暴露、估值排序或 shortlist。
- [x] 研报索引和研报材料目录始终以稳定形状出现在研究数据包中，即使没有研报或研报来源失败；本切片的本地 PDF 路径统一为 `来源缺失`。
- [x] 来源清单声明研报索引的来源名称、访问时间、回溯窗口、排序与限量口径、验证状态和缺失行为。
- [x] 检索成功但无记录时写入 `research_report_index_no_data`；请求或解析失败时写入 `research_report_index`，两者不能混淆。
- [x] 部分证券失败时保留成功证券的索引并返回成功；所有证券的索引请求都失败时，独立抓取入口先写完空索引、来源清单和错误记录，再返回非零。
- [x] 一键数据准备默认运行研报索引阶段；该阶段返回非零时只输出告警，核心股票池、行情、财务及既有数据包仍成功完成。
- [x] 东方财富请求具有超时、串行节流、有限重试和明确用户代理，不绕过登录、验证码、访问控制或源站限流。
- [x] 端到端 fixture 检查从一键准备公开入口覆盖成功、无数据、部分失败和全部失败场景，不访问真实网络。
- [x] 规范源中的 A 股数据来源契约和自动准备说明包含研报索引，命名 Agent bundle 通过现有同步流程保持一致。
- [x] 研报专项检查、现有 A 股数据契约检查、一键准备检查和仓库总检查全部通过，且未禁用既有测试。
