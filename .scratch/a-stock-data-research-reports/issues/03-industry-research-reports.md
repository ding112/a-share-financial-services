# 用显式行业代码扩展研报索引与 PDF

Status: ready-for-agent

## What to build

在个股研报索引和限量 PDF 已完整可用的基础上，允许使用者显式提供一个或多个东方财富行业代码，并把对应行业研报写入同一研报索引和同一研报材料目录。行业研报沿用个股研报的日期窗口、条数限制、下载限制、来源等级和失败语义。

系统不得从主题名称、概念板块或自然语言自动推断行业代码。没有显式行业代码时，不得发起行业研报请求。个股和行业报告通过范围类型及对象标识区分，不建立第二套输出契约。

## Acceptance criteria

- [ ] 独立研报抓取入口和一键准备入口接受零个、一个或多个显式东方财富行业代码。
- [ ] 未提供行业代码时不发起行业研报请求，现有个股研报行为和输出保持不变。
- [ ] 提供行业代码时只查询这些代码，不根据主题、概念或股票池自动增加其他行业。
- [ ] 行业研报与个股研报写入同一索引，通过范围类型、行业代码和行业名称区分；不新增平行索引文件。
- [ ] 行业研报默认使用截至 `as-of` 的 730 天窗口，每个行业最多索引 20 条并下载最新 3 份，且允许沿用公开参数调整。
- [ ] 行业研报按发布日期降序、稳定报告 ID 次序排序；索引身份同时保留范围类型、对象标识和报告 ID，PDF 内容按稳定报告 ID 复用。
- [ ] 行业研报索引和 PDF 统一标记为 `third_party`、`待验证`，不得自动进入行业规模、业务暴露、盈利预测或 shortlist 结论。
- [ ] 单个行业无数据、索引失败或 PDF 失败分别沿用既有 `research_report_index_no_data`、`research_report_index` 和 `research_report_pdf` 语义，并保留其他证券或行业的成功结果。
- [ ] 所有显式行业与股票索引请求均失败时，独立抓取入口返回非零；一键准备流程仍只告警并完成核心数据包。
- [ ] 来源清单能够说明索引中包含的个股与显式行业范围、访问时间、限量口径、来源等级和缺失行为。
- [ ] 端到端 fixture 检查覆盖未提供行业代码、单行业、多行业、个股与行业混合、行业无数据和行业部分失败，不访问真实网络。
- [ ] 规范源中的 A 股数据来源契约和使用说明解释行业代码必须显式提供，命名 Agent bundle 通过现有同步流程保持一致。
- [ ] 研报专项检查、现有 A 股数据契约检查、一键准备检查和仓库总检查全部通过。
