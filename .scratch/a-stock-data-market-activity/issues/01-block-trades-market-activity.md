# 01 — 贯通大宗交易市场行为事实

**What to build:** 为 A 股研究数据包建立第一条可运行的市场行为事实路径：以股票池和研究截止日为输入，通过东方财富公开数据中心完整抓取逐笔大宗交易，将稳定、限量、可审计且不包含未来表现的记录写入 `block_trades.csv`，并让一键准备流程默认执行该可选阶段。

本切片同时建立独立市场行为事实入口和一键准备接缝。它只交付大宗交易事实，但必须预留同阶段后续加入股东户数的参数与输出结构。大宗交易折溢价和营业部信息只描述交易本身，不生成机构吸筹、主力买卖、利益输送、资金意图或后续价格方向等判断。

**Blocked by:** None — can start immediately

**Status:** completed

- [x] 输入只读取股票池 `code` 列并规范化沪、深、北 A 股代码；不提供全市场扫描、主题推断或额外代码列表。
