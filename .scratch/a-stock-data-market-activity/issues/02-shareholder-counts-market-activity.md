# 02 — 扩展股东户数快照并收口双数据集契约

**What to build:** 在已经贯通的大宗交易市场行为事实阶段中加入股东户数历史快照：通过东方财富个股历史详情源完整分页，严格按统计截止日和公告日执行研究截止日可见性约束，把稳定、可审计的快照写入 `shareholder_counts.csv`。

本切片同时收口大宗交易与股东户数作为同一可选阶段时的组合行为：两个数据集各自保留无数据和失败状态，任何局部失败都不得清空另一数据集；只有两个数据集对全部有效证券均请求或解析失败时，独立入口才返回非零。一键准备流程始终只告警降级并继续核心研究包。

**Blocked by:** 01 — 贯通大宗交易市场行为事实

**Status:** completed

- [x] 独立市场行为事实入口和一键准备入口增加股东户数回溯天数及每证券上限；默认回溯 730 天、每证券最多保留最新 8 个可见快照。
- [x] 在线来源使用东方财富 `RPT_HOLDERNUM_DET` 个股历史详情并完整遍历分页；不得使用只表达全市场最新状态的 `RPT_HOLDERNUMLATEST`，户均持股数量必须映射 `AVG_HOLD_NUM`。
- [x] 股东户数有效窗口按统计截止日判断，并同时要求公告日存在且不晚于研究截止日；公告日在研究截止日之后的历史快照不得回填进过去的数据包。
- [x] 分页停止基于通过研究截止日、窗口和核心字段校验后的有效快照；首页被未来公告占据时仍继续分页查找当时已经公开可见的记录。
- [x] `shareholder_counts.csv` 具有规格约定的固定列顺序，至少包含稳定快照标识、证券标识、统计截止日、公告日、本次与上次户数、户数变化及其 basis、变化率及其 basis、户均持股、户均持股市值、总市值、总股本和来源元数据。
- [x] 输出统一使用基础计量单位：股东户数为户，户均持股和总股本为股，户均持股市值及总市值为人民币元，变化率为百分比；API 基础单位不得按网页的万或亿展示口径重复缩放。
- [x] 股东户数核心字段为证券代码、统计截止日、公告日和本次户数；缺失或非法时拒绝该行并记录 `shareholder_count`，可选字段缺失时保留行并写 `来源缺失`。
- [x] 户数变化来源值按整数精确核对；变化率允许最多 `0.02` 个百分点的舍入差异。来源缺失且基础字段足够时生成机械派生值并标记 `calculated`，来源值一致时标记 `source`，冲突时隔离派生字段并记录解析错误。
- [x] 非空响应全部被核心字段校验拒绝时属于 `shareholder_count` 解析失败，不得写成正常无数据。
- [x] 快照身份由证券代码、统计截止日和公告日组成，并生成带 `sh_` 前缀的稳定本地标识；结果按统计截止日降序、公告日降序、证券代码升序和稳定标识升序排列。
